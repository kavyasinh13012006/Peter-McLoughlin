# Peter McLoughlin — Multi-Page Website UI

A multi-page frontend website project organised around a personal or professional brand. The repository includes layouts for case studies, FAQs, mediation, policies, process information, and contact details.

## Tech Stack

- HTML5
- CSS3
- Responsive stylesheet
- Slick Carousel assets
- Custom fonts and local images

## Main Pages

- Home
- Case studies and case-study details
- FAQs
- Mediation
- Process
- Policy
- Contact

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a browser, or run it with VS Code Live Server.
3. Keep the `assests` directory in place so fonts, images, and styles resolve correctly.

## What This Project Demonstrates

Multi-page website structure, consistent visual styling, reusable assets, and frontend layout implementation. This repository documents the UI project and does not claim a connected production backend.
